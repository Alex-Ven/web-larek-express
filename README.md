# Web Larek

**Web Larek** — это веб-приложение для управления товарами и заказами. Оно предоставляет REST API для создания, получения, обновления и удаления товаров, а также для создания заказов с проверкой данных и логированием.

## Описание проекта

**Web Larek** — это серверное приложение, написанное на Node.js с использованием фреймворка Express. Оно предназначено для управления каталогом товаров и обработки заказов. Проект включает валидацию данных, централизованную обработку ошибок, логирование запросов и ошибок, а также поддержку MongoDB для хранения данных.

---

## Функциональность

1. **Товары:**
   - Получение списка всех товаров.
   - Создание нового товара с валидацией данных.

2. **Заказы:**
   - Создание нового заказа с проверкой товаров и суммы.
   - Валидация данных заказа (платеж, email, телефон, адрес и т.д.).

3. **Логирование:**
   - Логирование всех запросов в файл `request.log`.
   - Логирование ошибок в файл `error.log`.

4. **Обработка ошибок:**
   - Централизованная обработка ошибок с единообразным форматом ответа.
   - Поддержка пользовательских классов ошибок (например, `BadRequestError`, `ConflictError`).

---

## Технологии

- **Node.js** — среда выполнения JavaScript.
- **Express** — фреймворк для создания REST API.
- **MongoDB** — база данных для хранения товаров и заказов.
- **Mongoose** — ODM для работы с MongoDB.
- **Celebrate + Joi** — валидация входных данных.
- **Winston + Express-Winston** — логирование запросов и ошибок.
- **ESLint** — линтер для проверки качества кода.
- **Faker.js** — генерация уникальных ID для заказов.

## Настройка окружения

1. **Установите зависимости:**

   ```bash
   npm install
   ```

2. **Создайте файл `.env` для переменных окружения:**

   ```plaintext
   PORT=3000
   MONGO_URI=mongodb://127.0.0.1:27017/weblarek
   ```

3. **Инициализируйте базу данных MongoDB:**
   - Убедитесь, что MongoDB запущена на вашем компьютере или в Docker-контейнере.

---

## Запуск проекта

1. **Запустите сервер в режиме разработки:**

   ```bash
   npm run dev
   ```

2. **Запустите сервер в production-режиме:**

   ```bash
   npm start
   ```

3. **Проверьте работу API:**
   - Откройте [http://localhost:3000](http://localhost:3000) в браузере или используйте Postman/cURL для тестирования эндпоинтов.

---

## Логирование

1. **Логи запросов:**
   - Все запросы сохраняются в файл `request.log` в формате JSON.

2. **Логи ошибок:**
   - Все ошибки сохраняются в файл `error.log` в формате JSON.

3. **Игнорирование логов в Git:**
   - Файлы `request.log` и `error.log` добавлены в `.gitignore`.

---

## Обработка ошибок

1. **Централизованная обработка ошибок:**
   - Все ошибки обрабатываются в middleware `errorHandler`.
   - Формат ответа:
     ```json
     {
       "message": "Ошибка валидации данных"
     }
     ```

2. **Пользовательские классы ошибок:**
   - `BadRequestError` — ошибка валидации данных (код 400).
   - `ConflictError` — конфликт данных (например, дубликат товара, код 409).
   - `InternalServerError` — внутренняя ошибка сервера (код 500).

## Примеры запросов

### 1. Получение всех товаров

```bash
curl http://localhost:3000/products
```

Ответ:

```json
{
  "items": [
    {
      "_id": "662e97d0c2fed29cab5bf3db",
      "title": "Товар 1",
      "image": {
        "fileName": "test.png",
        "originalName": "test.png"
      },
      "category": "софт-скил",
      "description": "Описание товара",
      "price": 100
    }
  ],
  "total": 1
}
```

### 2. Создание нового товара

```bash
curl -X POST http://localhost:3000/products \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Новый товар",
    "image": {
      "fileName": "new_image.png",
      "originalName": "new_image.png"
    },
    "category": "софт-скил",
    "description": "Описание нового товара",
    "price": 100
  }'
```

Ответ:

```json
{
  "_id": "662e97dec2fed29cab5bf3dd",
  "title": "Новый товар",
  "image": {
    "fileName": "new_image.png",
    "originalName": "new_image.png"
  },
  "category": "софт-скил",
  "description": "Описание нового товара",
  "price": 100
}
```

### 3. Создание заказа

```bash
curl -X POST http://localhost:3000/order \
  -H "Content-Type: application/json" \
  -d '{
    "payment": "card",
    "email": "admin@ya.ru",
    "phone": "+7999999999",
    "address": "test",
    "total": 4200,
    "items": [
      "662e97d0c2fed29cab5bf3db",
      "662e97dec2fed29cab5bf3dd"
    ]
  }'
```

Ответ:

```json
{
  "id": "c1f83572-e756-4f82-809b-4c710fe51087",
  "total": 4200
}
```
